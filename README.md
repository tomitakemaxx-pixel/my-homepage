# シルクフラワーの山久 — 胡蝶蘭 商品紹介ホームページ

高級感のあるモダンなデザインで、シルクフラワー(造花)の胡蝶蘭を紹介するランディングページです。

## 構成

```
index.html      … ページ本体
css/style.css   … スタイル(アニメーション含む)
js/main.js      … 胡蝶蘭SVG生成・カラー切替・スクロール演出
```

静的サイトのため、`index.html` をブラウザで開くだけで動作します(GitHub Pages にそのまま公開可能)。

## 主な演出

- ローディングアニメーション(「祝」の文字)
- ヒーローの舞い散る花びらパーティクル・金色リングの回転
- SVGで描画した胡蝶蘭(3本立て)— 花が微かに揺れるアニメーション
- **選べる6色**のインタラクティブなカラー切替(ページ内の全ての胡蝶蘭が連動)
- スクロール連動のリビール演出・数値カウントアップ
- 贈る場面のマーキー(流れるテキスト)
- レスポンシブ対応・`prefers-reduced-motion` 対応

## 素材の差し替えについて

現在のビジュアルはSVGアートワークで構成しています。Higgsfield等で生成した
商品写真・動画に差し替える場合は、各 `orchid-stage` 要素(`index.html` 内の
`#heroOrchid` `#aboutOrchid` `#colorOrchid` `#specOrchid`)の中身を
`<img>` / `<video>` に置き換えてください。
